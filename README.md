# Project-Loop
This repository is for the game [Seconds In Eternity](https://low-ram-advantage.itch.io/seconds-in-eternity) which was created as [a part of the 2025 GMTK Game Jam](https://itch.io/jam/gmtk-2025/rate/3782212).

## Overview
The game is a 2D platformer where you play as a cyborg who must make it to the end of the loop in a world where his battery is running out by the second.

## How To Play
The controls of the game are simple:
* A/D/Left/Right to move
* Space to jump
* Shift to dash
* C to Slide
* S to Crouch
* F to Shoot
* E to Interact (broken)
* Esc to open the menu
